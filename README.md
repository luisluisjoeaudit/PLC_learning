# PLC_learning
Hands-on PLC, automation, and industrial control projects built while preparing for a career in Instrumentation, Controls, and OT Security.
Welcome to my industrial automation learning portfolio.

This repository documents my journey toward becoming an Instrumentation Technician, Controls/Automation Specialist, and eventually an OT Security professional.

## Goals

- Learn PLC programming using CODESYS
- Build industrial automation projects
- Learn Ladder Logic, Structured Text, and Function Block Diagram
- Practice troubleshooting and documenting control systems
- Develop industrial networking knowledge
- Prepare for a career in Controls, SCADA, and OT Security
